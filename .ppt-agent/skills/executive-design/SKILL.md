# executive-design

**Description**: 汇报PPT设计规范
**Type**: design
**Agent Scope**: design_chart, page_designer

## Rules
- 使用专业配色方案：主色#1a365d（深蓝）、辅色#2b6cb0（浅蓝）、背景#ffffff（白）
- 标题字体：32pt Microsoft YaHei Bold
- 正文字体：20pt Microsoft YaHei Regular
- 留白充足，内容密度适中
- 图表优先于文字，数据可视化
- 保持视觉一致性，避免风格混乱
- 使用高质量图片和图标
- 动画要简洁，避免花哨

## Color Scheme
- **primary**: #1a365d
- **secondary**: #2b6cb0
- **accent**: #3182ce
- **background**: #ffffff
- **text_primary**: #1a202c
- **text_secondary**: #4a5568
- **border**: #e2e8f0
- **success**: #38a169
- **warning**: #d69e2e
- **error**: #e53e3e

## Typography
- **title**: Microsoft YaHei 32pt bold (#1a365d)
- **subtitle**: Microsoft YaHei 24pt bold (#2b6cb0)
- **body**: Microsoft YaHei 20pt regular (#1a202c)
- **caption**: Microsoft YaHei 14pt regular (#4a5568)
