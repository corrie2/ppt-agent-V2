# executive-writing

**Description**: 面向高管汇报的slide写作规范
**Type**: markdown
**Agent Scope**: content, brief_outline

## Rules
- 使用金字塔原理组织内容：结论先行，以上统下
- 每页不超过5个要点，每个要点不超过2行
- 数据驱动，避免主观描述
- 使用主动语态，避免被动语态
- 专业术语保持一致
- 避免使用行业黑话，确保受众能理解
- 每个要点必须有数据或事实支撑
- 结论必须明确，避免模糊表述

## Structure
### cover
**Description**: 封面页
**Content**: 主题, 副标题, 汇报人, 日期, 部门
**Tips**: 主题要简洁有力，副标题说明汇报范围

### agenda
**Description**: 目录页
**Content**: 章节标题, 预计时间
**Tips**: 3-5个主要章节，每个章节预计1-2分钟

### background
**Description**: 背景页
**Content**: 问题/机会, 目标, 范围
**Tips**: 说明为什么要做这件事

### method
**Description**: 方法页
**Content**: 方案, 策略, 执行步骤
**Tips**: 说明怎么做

### result
**Description**: 结果页
**Content**: 数据, 成果, 对比
**Tips**: 用数据说话，避免主观描述

### summary
**Description**: 总结页
**Content**: 关键发现, 建议, 下一步
**Tips**: 给出明确的结论和可执行的建议

### qna
**Description**: Q&A页
**Content**: 常见问题, 联系方式
**Tips**: 预判可能的问题，准备答案

## Writing Tips
- **title**: 标题要简洁有力，能概括整页内容
- **bullet_points**: 每个要点不超过2行，使用动词开头
- **data**: 数据要准确，注明来源
- **conclusion**: 结论要明确，避免'可能'、'也许'等模糊词汇
- **action**: 建议要具体，可执行
