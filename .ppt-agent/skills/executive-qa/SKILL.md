# executive-qa

**Description**: 汇报PPT质量检查规范
**Type**: validation
**Agent Scope**: qa

## Rules
- 检查逻辑连贯性：每个章节是否承上启下
- 验证数据准确性：数据来源是否可靠
- 确保时间控制：每页1-2分钟，总计15-20分钟
- 检查专业术语一致性
- 验证图表是否清晰易懂
- 检查是否有错别字和语法错误
- 确保格式统一
- 验证链接和引用是否正确

## Checklist
### cover
- 主题是否清晰
- 副标题是否说明范围
- 汇报人信息是否完整
- 日期是否正确

### agenda
- 目录是否清晰
- 章节顺序是否合理
- 预计时间是否合理

### content
- 每个章节是否有明确结论
- 数据是否有来源说明
- 图表是否清晰易懂
- 要点是否简洁有力

### summary
- 总结是否概括要点
- 建议是否具体可执行
- 下一步是否明确

### overall
- 逻辑是否连贯
- 风格是否统一
- 时间是否控制在15-20分钟
- 是否有错别字
